PODAR PATHWAYS - phpMyAdmin & MySQL PRODUCTION DEPLOYMENT GUIDE
=============================================================================

1. UPLOAD FILES TO CPANEL:
   - Log into your cPanel File Manager.
   - Navigate to 'public_html' (or your target domain web root).
   - Upload 'podar-pathways-production.zip' (or 'public.zip').
   - Extract the zip file directly in 'public_html'.
   - IMPORTANT (Dotfiles / Hidden Files): By default, cPanel hides files starting with a dot (.env, .htaccess).
     If you don't see '.env' or '.htaccess', click "Settings" in the top-right corner of cPanel File Manager,
     check "Show Hidden Files (dotfiles)", and click "Save".
   - Ensure 'index.html', '.htaccess', '.env', 'api/', and 'assets/' are in the web root.

2. IMPORT THE DATABASE IN phpMyAdmin:
   - In cPanel, go to "MySQL Databases" and create the database(s):
       * Main DB:         mpoda209_pathways      (or podar_pathways)
       * Certificates DB: mpoda209_certificates  (or podar_certificates)
       * Projects DB:     mpoda209_projects      (or podar_projects)
     (Tip: You can also use a single database name for all 3 if preferred.)
   - Create a database user, assign ALL PRIVILEGES, and add to the database(s).
   - Open "phpMyAdmin".
   - Select your database and click "Import".
   - Choose the included 'database.sql' and click "Go / Import".
   - The tables and default administrator (jatp22316@gmail.com) will be set up.

3. CONFIGURE .env:
   - Open '.env' (in the web root or inside 'api/').
   - Verify/update your MySQL credentials:
       DB_DRIVER=mysql
       DB_HOST=localhost
       DB_PORT=3306
       DB_NAME=mpoda209_pathways
       DB_USER=mpoda209_admin
       DB_PASS=Admin@2026!
       DB_CERTIFICATES_NAME=mpoda209_certificates
       DB_PROJECTS_NAME=mpoda209_projects
   - Set SMTP email credentials for live OTP delivery:
       SMTP_HOST=mail.podarpathways.com
       SMTP_PORT=465
       SMTP_SECURE=ssl
       SMTP_USER=noreply@podarpathways.com
       SMTP_PASS=noreply@podar.com
       EMAIL_FROM="Podar Pathways Academic Board <noreply@podarpathways.com>"

4. PURE phpMyAdmin / MySQL ARCHITECTURE:
   - Strictly uses MySQL / phpMyAdmin. No SQLite files or fallbacks are included.
   - Zero demo entries, zero sample students. Ready for real production deployment.
